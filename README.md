# PawHome - Pet Adoption Management System

PawHome is a web-based platform that connects animal shelters with people who want to adopt. It replaces manual, paper-based adoption records with one online system for listing pets, applying to adopt, and tracking each request.

**Live website:**  https://harshavarthini-b.github.io/Pet-Adoption/

## Features

- User registration and login (adopters and shelters)
- Pets of many kinds: dogs, cats, rabbits, birds, small pets, reptiles and more
- Live photos taken from the device camera, or uploaded from the device
- Search and filter by name, breed, kind, age, gender and city
- Adoption request form with a short questionnaire
- Request tracking: Pending, Under review, Approved, Adopted
- Shelter dashboard to post, edit and delete pets and to approve or decline requests
- Admin dashboard to create users, delete users, reset passwords, change roles and manage all pets and requests

## User roles

| Role | What they can do |
|---|---|
| Adopter | Browse pets, send adoption requests, track status |
| Shelter / organisation | Post pets with photos, manage requests |
| Administrator | Everything above, plus manage all users |

## Technology

HTML, CSS and JavaScript in a single file (`index.html`). Passwords are stored as salted PBKDF2 hashes. On GitHub Pages, data is saved in the browser's local storage.

## How to run

Open `index.html` in a browser, or visit the live website link above.
